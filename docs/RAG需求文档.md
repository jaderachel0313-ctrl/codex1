# RAG 双模式切分与评测需求文档（演示原型）

版本：草案 v0.1  
日期：2026-10-09

## 1. 目标与范围

建设一个可演示的 RAG 知识库原型。用户上传文档后，先选择「自动模式」或「自选模式」，再执行切分与索引构建。系统支持基于知识库的问答、可定位到原文的引用、切块预览、策略比较和索引版本回退。原型验证通过后再规划长期运行版本。

首版目标是展示完整闭环和可解释的比较结果；不将自动生成测试题的成绩宣称为真实用户问题的召回率。

## 2. 已确认的产品决策

1. 文档上传后先解析并生成文档画像，再由用户选择模式；确认模式后才正式切分、建立索引。
2. 自动模式根据文档画像选择切分策略和参数，质检不通过时尝试后备策略。
3. 自选模式可从适用策略中选择多个候选、调整参数、查看切块预览和评分，再确定正式方案。
4. 自选模式同时包含快速切块质量比较和基于自动生成测试题的深入检索评测。
5. 用户选择的方案成为正式索引版本；旧正式版本在保留期内可回退。未选中的候选索引是临时资源，保留配置与评测记录，索引按数量和时间清理。
6. 允许调用模型服务；具体服务商、存储位置与数据流出要求尚未确定。

## 3. 用户流程

### 3.1 上传与模式选择

`上传文件/压缩包 → 格式与大小校验 → 解析与原文定位 → 文档画像 → 选择模式 → 切分 → 建索引 → 问答`

支持单独上传和批量上传。每个文件显示接收、解析、等待选择模式、建索引、可用或失败状态。批量上传中单个文件失败不应阻断其余文件。解析后的结构预览应能暴露标题、正文、表格、页码等问题。

### 3.2 自动模式

根据文档画像生成有序候选链：结构清晰时优先标题层级切分；存在章节编号或其他可靠边界时尝试启发式切分；递归切分兜底。表格、问答对和演示文稿使用相应的结构保护规则。每次切分后进行基础质检；失败则尝试下一候选。展示最终采用的策略、主要参数与切块预览。

### 3.3 自选模式

按文档类型推荐适用模板与候选策略，推荐不构成硬性排除；用户可查看全部策略。初始比较建议 2～3 个候选，单轮上限建议 5 个，具体上限为可配置项。修改参数后先生成切块预览，不自动重建正式索引。后台异步执行候选比较；用户确认后才将所选候选发布为正式版本。

## 4. 文件格式与限制

| 类别 | 格式 | 单文件上限 |
|---|---|---:|
| 大文件文档 | PDF、DOCX、PPTX、DOC、WPS、OFD | 200 MB |
| 表格与文本 | XLSX、XLS、CSV、TXT、HTML、MD | 20 MB |
| 压缩包 | ZIP、TAR.GZ | 包内每个文档分别符合对应格式的单文件上限；压缩包本身及解压后总量上限待定 |

压缩包仅处理允许的文件类型；拒绝路径穿越、嵌套压缩包无限展开及超出解压限制的条目。扫描件、图片、公式和图表的解析质量需在样本验收中确认；是否引入 OCR 或多模态解析待定。对于不能可靠解析的文件，应展示具体失败原因，不生成空索引。

## 5. 文档画像与切分策略

画像基于统一解析结果，统计总长度、标题层级与密度、章节编号、段落长度、分页符、表格与列表占比、短碎文本比例等；它只推荐策略与初始参数，不参与候选结果评分。画像无需大语言模型即可实现。

| 模板 | 适用内容 | 候选策略或规则 |
|---|---|---|
| General | 普通正文 | 递归切分；固定长度仅作对照基线 |
| Q&A | 成对问答数据 | 每组问答保持为一个逻辑单元 |
| Book / Manual / Paper | 长篇、手册、论文 | 标题层级与章节边界；保护步骤、公式及引用上下文 |
| Laws | 法规、合同 | 章／条／款边界及编号元数据 |
| Table | XLSX、XLS、CSV及文内表格 | 行或行组切分，保留表头与行列定位 |
| Presentation | PPTX | 幻灯片为基本单元，超长页再细分 |
| One | 短文档 | 全文一块，超出 token 上限时不可选 |

父子块是可组合的检索方案：子块用于检索，父块用于提供回答上下文。首版候选重点包括递归、标题层级、启发式边界、父子块和表格行组；语义切分可作为后续扩展。具体参数初始值由画像建议并允许用户修改；所有大小参数须明确使用 token 或行数，不混用字符数。

## 6. 自选参数与预览

通用参数：目标块大小、最大块大小、最小块大小、重叠量。结构策略可设置标题级别、分隔符与过小块合并阈值；父子块可分别设置父块和子块大小；表格策略可设置每块行数、表头范围。参数需校验重叠量小于块大小、子块小于父块、单块不超过模型与索引约束。

预览显示块数、长度分布、过短和超长块比例、块内容、标题路径、原文位置以及表格边界。修改参数只重新切分预览；点击「运行深入评测」后才为候选建立临时索引。

## 7. 比较与指标

### 7.1 快速切块质量

基础指标包括结构块完整率（BI）、大小合格率（SC）、边界合理率及重复索引占比。可选增强指标包括块内聚性（ICC）、文档上下文连贯性（DCC）及指代完整性（RC）；后三项需要嵌入或共指模型，不能称为纯规则指标。各指标定义、权重、适用文档类型和缺失指标的重新归一化规则应在实现前固定并随评分版本记录。质量分只评价切块，不代表实际检索命中率。

### 7.2 深入检索评测

系统在任何待比较策略切分之前，从统一解析后的原文生成同一批测试问题、预期答案和一处或多处必要依据，并保存原文位置。生成可由大语言模型完成，程序核验位置、可回答性和重复题。问题按章节及内容类型抽样；合格题不足时展示实际题数，不输出误导性的稳定结论。

所有候选使用相同测试问题、嵌入模型、检索配置、Top-K 和返回上下文 token 预算。输出完整依据命中率@K、平均依据覆盖率@K、完整命中倒数排名、检索耗时和索引资源消耗。前端将命中率标注为「自动测试题上的完整依据命中率」，并显示命中题数／总题数；不得标为真实用户问题召回率。引用依据是否命中以解析后的原文位置或表格单元 ID 判断，不以关键词次数判断。

### 7.3 引用准确性验收

每条问答引用必须关联实际交给回答模型的检索内容，并能打开到相应原文位置。自动测试题用于开发期比较；原型验收另需一小批人工核对的真实问题，分别检查「引用确实支持回答」和「引用定位正确」。量化准确率目标及题量待定，未完成人工核对前不宣称达标。

## 8. 索引与版本生命周期

索引版本关联文档版本、解析版本、策略、参数、嵌入模型及评测版本。相同输入和配置可复用已有候选；参数变化时创建新候选。用户确认后，先验证新索引可检索，再原子切换正式版本；切换期间旧版继续服务。保留上一正式版本供回退。未选中临时索引按时间与数量上限清理，配置、评分与评测记录继续保留；清理后重新选择需重建。建议的「24 小时、最多 5 个」和「旧正式版本 7 天」均为原型默认提议，尚待确认。

## 9. 模型使用与数据边界

正式问答调用大语言模型；自动测试题生成调用大语言模型。ICC、DCC 使用嵌入模型，RC 使用共指模型；基本解析、画像、规则切分、BI 和 SC 可不使用大语言模型。文件存储在本机、项目服务器或对象存储尚待确定。若使用外部模型，发送给服务商的文档片段、测试题和用户问题应在界面或配置中明确说明。模型提供商、凭据管理、日志保留和数据删除规则待定。

## 10. 原型验收与异常处理

- 对规定格式执行上传大小校验、解析、切分和索引；单文件失败不会拖垮整批。
- 用户能在切分前选择模式；自动模式可展示选策原因和结果，自选模式可调整参数、预览、比较并确认。
- 问答引用可定位到原文；引用缺失或证据不足时不得伪造引用。
- 新正式索引构建失败时旧版继续可用；用户可回退到保留的旧版本。
- 深入评测展示测试题数、完整依据命中率及限制说明；同批候选比较条件一致。
- 临时索引能自动清理，清理后配置及历史评测记录仍可查看。
